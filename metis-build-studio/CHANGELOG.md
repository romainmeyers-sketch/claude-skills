# metis-build-studio v1.3: design systems in Claude Design
1. Builds full client design systems in Claude Design from the brand files people upload in the Studio (logos, guidelines, decks, fonts), then links the system back so every build can use it.

# metis-build-studio v1.2: attachments and the new look
1. Requests can carry files the person attached (PDF, Word, PowerPoint, Excel, text, images): build from them first; originals of PDFs, images and text are in the Studio's asset store.
2. House look for every deck, course and document: no dot separators, no bullet marks, no kicker-and-accent-bar openers; an icon on every point and a different layout each slide.

# metis-build-studio v1.1: every kind of work
1. Builds any Studio request, not only trainings: PRDs, product management, operating model and POM, AI strategy, SteerCos, proposals, case studies, points of view.
2. Follows the skill the request names (picked by the person or routed by the Studio), and the firm structure for each kind.
3. New formats: Word documents, branded PDFs and Excel models.

# metis-build-studio v1.0: first worker
1. Builds Build Studio requests on the requester's own computer and reports progress back to the Studio.
2. One skill per format: metis-pptx, metis-learning-module, metis-html-slides, metis-narrative-scroll; video requests become a Video Hub project.
3. Asks questions through the Studio, applies revisions as new versions, and can keep watching while the chat is open.
